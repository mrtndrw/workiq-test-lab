# Security

## Report a vulnerability

Do not open a public issue for a suspected vulnerability.

Use the repository's **Security** tab to open a private GitHub security advisory.
Include:

- The affected commit or release.
- Reproduction steps.
- Expected and observed behavior.
- Impact and any known workaround.

Do not include live credentials, bearer tokens, tenant work data, or personally
identifiable information. Replace sensitive values with clearly marked
placeholders.

## Deployment responsibility

This lab processes delegated Microsoft 365 work data. Operators are responsible
for tenant approval, spending-policy scope, enterprise-app assignment, secret
storage, HTTPS termination, logging, retention, and compliance requirements.
Follow [docs/tenant-setup.md](docs/tenant-setup.md) before deployment.
